# Columbia Asia Hospital Analysis | SQL & Power BI

## Project Overview
This project focuses on analyzing hospital operational data using SQL and Power BI. The objective is to understand patient visits, waiting times, department performance, patient demographics, and revenue patterns through data analysis and interactive visualizations.

## Business Objectives
- Analyze patient visits across different hospital departments.
- Evaluate average patient waiting time.
- Understand patient demographics and age distribution.
- Analyze doctor-patient and hospital operational metrics.
- Explore hospital revenue and visit patterns.

## Tools & Technologies
- SQL
- Microsoft Power BI
- Data Analysis
- Data Visualization
- Dashboard Development

## Key Insights
- Average patient waiting time: 35.26 minutes.
- General Practice recorded 7,240 department visits.
- Senior patients accounted for approximately 23.85%.
- Total revenue analyzed: $510 million across 9,216 visits.



## Conclusion
The project provides insights into hospital operations, patient demographics, department performance, waiting times, and revenue. SQL and Power BI were used to analyze the data and present findings in an understandable visual format.
